
# DI SẢN VIỆT

## Giới thiệu
Website lưu trữ và giới thiệu truyện dân gian địa phương.

## Công nghệ sử dụng
- HTML: xây dựng cấu trúc trang web.
- CSS: thiết kế giao diện.
- JavaScript: xử lý chức năng.
- Supabase: quản lý cơ sở dữ liệu và hình ảnh.
- GitHub Pages: triển khai website.

## Cấu trúc dự án
- index.html: trang web chính.
- style.css: giao diện.
- app.js: chức năng.
- config.js: cấu hình kết nối.
- README.md: tài liệu dự án.
